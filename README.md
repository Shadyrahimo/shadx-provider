# مستكشف ومربط منتجات المزودين | Digital API Catalog Explorer

منصة احترافية موجهة لتجار ومتاجر المنتجات الرقمية (بطاقات الألعاب، اشتراكات البث، نقاط الشات، البطاقات الرقمية)، تتيح جلب وتصفح وفلترة كتالوجات المزودين عبر الـ API (مثل **Mersal Card** و **Tartousi Store** و **Alkasr VIP** أو أي مزود مخصص)، مع الكشف الذكي عن المعلمات المطلوبة وحساب هوامش الربح وتوليد كود الربط المباشر بضغطة زر.

---

## 🌟 الميزات الرئيسية

1. **دعم كامل لقوالب مزودي البطاقات (Mersal Standard API)**:
   - دعم مباشر للمزودين المرفق توثيقهم:
     - `https://api.mersal-card.com/` (مرسال كارد)
     - `https://api.tartousi-store1.com/` (متجر طرطوسي)
     - `https://api.alkasr-vip.com/` (القصر VIP)
     - دعم أي مزود مخصص (Custom Base URL + Token).
2. **جدول كتالوج متكامل مع 11 عمود مخصص بدقة**:
   1. **المعرف (ID)** مع إمكانية النسخ الفوري.
   2. **اسم المنتج** مع الفئة الفرعية.
   3. **الفئة / التصنيف (Category)** مع تصنيف مرتب.
   4. **سعر التكلفة (USD)** بالأرقام المجدولة الدقيقة.
   5. **سعر البيع المقترح ($)** المحسوب تلقائياً حسب هامش الربح المحدد ونسبة الربح الصافية.
   6. **الحالة** (متاح / غير متوفر).
   7. **نوع الكمية** (باقة Package / كمية مرنة Amount / محددة Fixed).
   8. **الحدود (Min-Max)** مثل `1 - 15000` أو الخيارات الثابتة.
   9. **المعلمات المطلوبة (Required Parameters)** مع تصنيف ذكي للمفاتيح:
      - `EMAIL` (البريد الإلكتروني)
      - `player_id` (معرف اللاعب / Player ID / UID)
      - `server_id` (معرف الخادم / Zone ID)
      - `username` (اسم المستخدم / User ID)
      - `phone` (رقم الهاتف / الرقم)
   10. **الإجراءات (Actions)**:
       - فحص استعلام الطلب (`/client/api/newOrder/{id}/params`).
       - نسخ كائن JSON للربط البرمجي.
       - توليد قالب منتج لمنصة **سلة (Salla)** أو **زد (Zid)** أو **WooCommerce**.
       - كود جاهز بـ JavaScript (Fetch) و cURL.
   11. **فلاتر ذكية وسريعة**:
       - بحث فوري بالاسم والمعرف والفئة.
       - فلترة حسب التصنيف مع عداد المنتجات.
       - فلترة حسب التوفر ونوع الكمية ونوع المعلمة المطلوبة.
       - تحديد نطاق أسعار التكلفة (من - إلى).
       - فرز تصاعدي وتنازلي وبالاسم وهامش الربح.
3. **تصدير مجمّع احترافي**:
   - تصدير فوري إلى **Excel (CSV)** مع ترميز UTF-8 يدعم الحروف العربية بشكل كامل.
   - تصدير بصيغة **JSON**.
   - نسخ قائمة المعرفات المحددة (IDs List) لاستخدامها في الربط الجماعي.
4. **بروكسي داخلي آمن (Express Server)**:
   - حل نهائي لمشكلة قيود CORS لمتصفحات الويب عند استدعاء سيرفرات المزودين.
   - التعامل الذكي مع رموز الخطأ (120, 121, 122, 123, 100, 105, 107, 109, إلخ).

## 🚀 دليل بيئة التشغيل والنشر (GitHub + Vercel / Render + Neon)

### 1. التشغيل المحلي (Local Development)
```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير مع البروكسي
npm run dev
```
يفتح التطبيق على: `http://localhost:3000`

### 2. النشر على Render
1. قم برفع المستودع إلى حسابك في **GitHub**.
2. في لوحة تحكم **Render**، اختر **New Web Service**.
3. اربط مستودع GitHub.
4. الإعدادات الموصى بها:
   - **Environment**: `Node`
   - **Build Command**: `npm run build`
   - **Start Command**: `npm start`
   - **Port**: `3000`

### 3. النشر على Vercel
1. اختر **Import Git Repository** من Vercel.
2. يتم بناء التطبيق تلقائياً عبر `npm run build` ومسار الخرج `dist`.
3. للتعامل مع البروكسي في Vercel Serverless Functions، يمكن توجيه مسارات `/api/*` بسهولة.

### 4. الربط مع قاعدة بيانات Neon Console (اختياري عند الرغبة في تخزين مفاتيح المزودين بشكل دائم)
- قم بإنشاء قاعدة بيانات PostgreSQL على **Neon Console**.
- انسخ `DATABASE_URL` وأضفها إلى متغيرات البيئة في Render أو Vercel.
